Connectez-vous avec votre compte Microsoft Regen School. Vos modules et vos étudiants s'affichent ; vous créez vos épreuves, saisissez les notes, puis les soumettez. Une note soumise est définitive : elle est transmise à l'espace Notion de l'étudiant.

Une note soumise est définitive : elle ne peut plus être modifiée depuis cette page. En cas d'erreur, contactez l'équipe pédagogique. Pour une absence, laissez la case vide.
